# City Bus Shift privacy policy page

1. Replace every `[DEVELOPER NAME]` and `[CONTACT EMAIL]` in `index.html` before publishing (they appear in both languages).
2. Free hosting option A: create a separate public GitHub repo, put `index.html` at its root, enable Settings > Pages (deploy from `main`); the URL is `https://<user>.github.io/<repo>/`.
3. Option B: paste the content into a Google Sites page and publish it.
4. Put the resulting public URL in Play Console > App content > Privacy policy.
